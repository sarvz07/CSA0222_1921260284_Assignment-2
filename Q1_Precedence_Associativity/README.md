# Q1 – Precedence and Associativity

This section covers the pharmacy billing problem and the `count = count++ + 1` undefined behaviour discussion.

Key points:
- Understand operator precedence in arithmetic expressions.
- Explain how integer division affects the result.
- Demonstrate the difference between a single expression and intermediate variables.
- Explain why `count++` in an expression is undefined behaviour in C.

Sample program output format:
- Bill before discount
- Discount amount
- GST amount
- Final payable amount

The corrected implementation should use intermediate variables to avoid ambiguity and to make the logic easier to explain during viva.
